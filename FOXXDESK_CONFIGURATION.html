Arquitetura V6

O rebrand é aplicado localmente e commitado. O GitHub Actions não modifica o checkout durante o build. Isso garante que Windows, Linux, macOS, Android e iOS compilem a mesma árvore.

Importante: na V6 o rebrand não é mais reaplicado escondido dentro de cada job do Actions. Essa mudança elimina a dependência de inserir um hook depois de cada actions/checkout do RustDesk.

iOS é achatado sem transparência; Android notification usa máscara apropriada; ICO contém múltiplas resoluções; ICNS é gerado para macOS.

`hbb_common` submodule-safe

libs/hbb_common permanece upstream e limpo. Para RustDesk 1.4.9, o pin conhecido é 7e1c392c62d39c364127307cd408421dd5f8cfb0.

  • V6 remove automaticamente apenas alterações FoxxDesk legadas reconhecidas.
  • Alteração local desconhecida não é apagada: o prepare para e pede revisão.
  • Versões novas tentam resolver o gitlink da mesma versão/ref do RustDesk.
  • Staging fallback no Windows fica no mesmo volume do workspace.
git -C libs/hbb_common status --short
git -C libs/hbb_common diff

GitHub Actions

O workflow FoxxDesk é manual:

on:
  workflow_dispatch:

O composite de preflight executa somente:

python scripts/foxxdesk_validate.py --target . --ci

Não há gatilho em push/PR/schedule, não há Pillow no runner e nenhum hook é injetado em flutter-build.yml ou bridge.yml.

`foxxdesk_prepare.py`

python3 scripts/foxxdesk_prepare.py --target . --apply --yes --sync-deps
ArgumentoFunção
--applyAplica preparação local.
--dry-runPlaneja sem aplicar.
--ciSomente valida; não modifica.
--bootstrapUsa perfil full de primeira conversão/auditoria.
--sync-depsConfere/sincroniza hbb_common se necessário.
--force-sync-depsDescarta conscientemente alterações do submódulo e restaura o pin.
--profilesafe, runtime ou full.
--skip-iconsPula ícones.
--skip-validatePula validação final; não recomendado.

Runtime defaults

scripts/foxxdesk_runtime_defaults.py gera src/foxxdesk_defaults.rs e aplica patches mínimos marker-based em src/lib.rs, src/common.rs, src/client.rs e src/rendezvous_mediator.rs.

Isso mantém nome runtime, rendezvous, relay e chave no repositório principal. Se um anchor mudar em uma futura versão, o prepare falha explicitamente.

python3 scripts/foxxdesk_runtime_defaults.py --target . --check

Build wrapper

python3 scripts/foxxdesk_build.py --target . --dry-run
python3 scripts/foxxdesk_build.py --target . --prepare

O wrapper traduz somente opções compatíveis com o build.py e a plataforma: Flutter, hwcodec, portable/VRAM no Windows, unix-file-copy-paste, ScreenCaptureKit no macOS e opções de skip/package quando disponíveis.

Regras de segurança

  • Não altera o .gitignore nem o .gitattributes da raiz.
  • Não carrega snapshots de workflows upstream no pacote.
  • Não substitui arquivos upstream inteiros quando patch cirúrgico basta.
  • Não apaga mudança desconhecida do submódulo.
  • Não usa ícone fallback sem verificação de hash.
  • Não tenta adivinhar APIs futuras: falha cedo quando um anchor muda.
